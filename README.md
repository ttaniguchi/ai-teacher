# 技術質問ノート

開発や学習の途中で浮かんだ技術的な疑問を、あとから読み返せる形で残すための静的サイトです。

## このリポジトリの趣旨

- **1 HTML = 1 つの質問**  
  各ページは、ひとつの技術的な疑問をテーマにしています。ファイル名はトピックを表す英小文字のハイフン区切り（例: `nodejs-versions.html`）です。

- **簡潔な回答と、詳しい説明**  
  ページ上部の「簡潔なQ&A」で要点をすぐ把握し、その下の本文で背景・仕組み・比較・注意点などを体系的に説明します。必要に応じて図解（SVG）や比較表も含みます。

- **個人の知識ベースとして蓄積**  
  ブログや公式ドキュメントの代わりではなく、「自分が一度疑問に思ったこと」と「そのときの理解」をメモとして残す場所を想定しています。

## コンテンツについて（重要）

**本サイトに掲載されている回答・解説の本文は、すべて AI（大規模言語モデル）による生成です。**

- 人間によるファクトチェックや専門家レビューを経ていない場合があります。
- 技術の仕様・バージョン・ベストプラクティスは日々変わるため、**必ず公式ドキュメントや一次情報と照合してから**本番や重要な判断に使ってください。
- 誤りや古い情報に気づいた場合は、該当 HTML を更新するか、新しい質問として追記してください。

## 閲覧方法

**GitHub Pages** で公開する想定です。ビルドツールは不要で、リポジトリ内の HTML / CSS / 画像をそのまま配信します。

### 公開 URL（想定）

リポジトリ `ttaniguchi/ai-teacher` をルートから公開する場合:

**https://ttaniguchi.github.io/ai-teacher/**

（`main` ブランチへ push し、GitHub の Pages 設定が有効になったあとにアクセスできます）

### GitHub Pages の設定

1. GitHub でこのリポジトリを開く
2. **Settings** → **Pages**
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch を `main`、フォルダを **`/ (root)`** にして Save
5. 数分後、上記 URL で `index.html` がトップとして表示される

相対パス（`styles/site.css` や `../images/...`）は、ルート配信のままで問題なく動きます。

### ローカルで確認するとき

公開前のプレビュー用です。`file://` で直接開くより、簡易サーバー経由のほうがリンク確認しやすいです。

```bash
# このディレクトリで
python3 -m http.server 8080
# ブラウザで http://localhost:8080/index.html
```

エントリーポイントはルートの [index.html](./index.html) です。記事一覧と各ページへのリンクがあります。

## ディレクトリ構成

```
.
├── index.html              # トップ（記事一覧・ナビゲーション）
├── README.md               # 本ファイル
├── styles/
│   └── site.css            # 共通スタイル
├── images/                 # 図解（SVG など）
├── ai-development/         # AI 開発まわりの質問
└── programming/              # プログラミング・Web まわりの質問
```

記事の一覧は [index.html](./index.html) を正とします。新しい質問を追加するときは、トピック用ディレクトリに HTML を1つ追加し、`index.html` にエントリを足してください。

## ページの典型的な構成

各 HTML 記事は、おおよそ次の順序で書かれています。

1. ヒーロー（質問を表す見出しとリード文）
2. **簡潔な Q&A**（`section.qa` — 質問と短い回答）
3. 本文（見出し付きの詳細説明）
4. **要点**（まとめ）
5. 関連ページへのナビゲーション
